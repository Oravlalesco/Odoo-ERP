### Fase 32 — Value Added Services (VAS)
**Servicios de valor agregado.** Operaciones adicionales sobre la mercadería:

| Servicio | En inglés | Significado |
|---|---|---|
| **Etiquetado** | Labeling | Aplicar etiquetas especiales del cliente |
| **Re-empaque** | Repacking | Cambiar el empaque original |
| **Kitting** | Kitting | Ensamblar un kit de múltiples productos |
| **Ensamblaje** | Assembly | Ensamblaje ligero de componentes |
| **Inspección** | Inspection | Inspección especial por requerimiento del cliente |
